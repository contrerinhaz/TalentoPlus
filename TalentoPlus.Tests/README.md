# TalentoPlus.Tests

## Description
TalentoPlus.Tests contains the unit and integration tests for the TalentoPlus solution. It ensures the reliability and correctness of the business logic and API endpoints.

## Running Tests
To run the tests, use the .NET CLI or your preferred IDE's test runner.

### Using .NET CLI
1. Navigate to the project directory.
2. Run the following command:
   ```bash
   dotnet test
   ```

## Test Structure
- **UnitTests**: Tests for individual components and services in isolation.
- **IntegrationTests**: Tests that verify the interaction between different parts of the system.
